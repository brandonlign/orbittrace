# Sensitivity to analysis choices

A real signal should not disappear when a reasonable quality cut or window width is changed slightly. The candidate was therefore tested under every combination of four choices:

- maximum trajectory-fit error: 120, 180, or 240 arcsec;
- minimum participating stations: 2, 3, or 4;
- radiant/speed core radius: 2.5σ, 3.0σ, or 3.5σ; and
- activity half-width: 3°, 4°, or 5° solar longitude.

This produced 81 settings. Each used the same March–May 2022–2026 catalogues and the same expanded antihelion background. Orbital elements were not used to select the activity enhancement.

## Results

| Measure | Value |
|---|---:|
| Settings tested | 81 |
| Settings passing | 81 |
| Member-count range | 29–129 |
| Median orbital-D range | 0.03640–0.05548 |
| Smallest activity p-value | 2.82 × 10⁻²⁶ |
| Median activity p-value | 1.76 × 10⁻¹³ |
| Largest activity p-value | 8.55 × 10⁻⁷ |

Even the stricter settings requiring four stations, a 2.5σ core, and a three-degree half-window retained roughly 29–30 members and a compact orbit.

The result does not depend on one unusually favorable choice of fit error, station count, core radius, or activity window. These settings overlap heavily, so they should be read as one sensitivity analysis rather than as 81 independent replications.
