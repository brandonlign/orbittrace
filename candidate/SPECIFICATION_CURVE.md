# Sensitivity to analysis choices

I tested the candidate under every combination of four reasonable analysis choices:

- maximum trajectory-fit error: 120, 180, or 240 arcsec;
- minimum participating stations: 2, 3, or 4;
- radiant/speed core radius: 2.5σ, 3.0σ, or 3.5σ; and
- activity half-width: 3°, 4°, or 5° solar longitude.

The 81 settings all used the same March–May 2022–2026 catalogues and expanded antihelion background. Selection used radiant, speed, and solar longitude, with orbit evaluated afterward.

## Results

| Measure | Value |
|---|---:|
| Settings tested | 81 |
| Settings passing | 81 |
| Member-count range | 29–129 |
| Median orbital-D range | 0.03640–0.05548 |
| Smallest activity p-value | 2.82 × 10⁻²⁶ |
| Median activity p-value | 1.76 × 10⁻¹³ |
| Largest activity p-value | 8.55 × 10⁻⁷ |

Even the stricter settings requiring four stations, a 2.5σ core, and a three-degree half-window retained roughly 29–30 members and a compact orbit.

The signal remained significant and orbitally compact across the full grid. Because the settings overlap heavily, this is one sensitivity analysis, not 81 separate replications.
